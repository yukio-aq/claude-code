# セキュリティルール

## 絶対禁止

- APIキー・シークレット・パスワードをソースコードにハードコードしない
- `.env` ファイルを Git にコミットしない（`.gitignore` に必ず追加）
- `console.log` に認証情報・個人情報を出力しない
- デバッグ用の認証バイパス（`if (dev) skipAuth()`）をコミットしない

## 入力バリデーション

- 外部からの入力はすべてバリデーションする（Zod / Pydantic）
- SQLクエリは必ずパラメータ化する（文字列結合禁止）
- HTMLへの出力は必ずエスケープする（XSS防止）
- ファイルパスにユーザー入力を使う場合はサニタイズする（パストラバーサル防止）

## 認証・認可

- 認証と認可は別で実装する（authn / authz を混同しない）
- JWTは必ず検証する（`alg: none` 攻撃対策）
- セッションIDはログイン後に必ず再生成する
- 管理者権限が必要なエンドポイントは必ず認可チェックを入れる

## 依存ライブラリ

- 新しいライブラリを追加する前に必ず承認を得る
- インストール時は `npm audit` / `pip-audit` を実行する
- メンテナンスが停止しているライブラリは使わない

## エラーハンドリング

- エラーレスポンスにスタックトレースを含めない（本番環境）
- エラーメッセージにシステム内部情報を露出しない
- 認証失敗は「メールアドレスまたはパスワードが違います」で統一（列挙攻撃対策）
