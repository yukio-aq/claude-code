domain-analyst エージェントを起動して、顧客業界のドメイン知識を収集・構造化します。

## 使い方

```
/domain
/domain --industry 建築
/domain --industry 小売 --focus 在庫管理
```

## オプション

| オプション | 説明 |
|---|---|
| （なし） | 業界名をインタラクティブに確認してから開始 |
| `--industry {業界名}` | 指定業界で直接調査を開始 |
| `--focus {領域}` | 調査のフォーカス領域を絞る |

## 実行内容

```
1. domain-analyst を起動
2. Web検索で業界の構造・用語・課題を調査
3. ユビキタス言語（用語集）を構築
4. ドメインモデルの骨格（エンティティ・関係）を作成
5. 業界課題・ペインポイントを推察
6. ヒアリング深掘り質問リストを生成
7. docs/domain/ にレポートを出力
```

## 出力先

- `docs/domain/{業界名}-domain-YYYY-MM-DD.md`

## 次のステップ

出力されたレポートを上流工程チームに渡します。
要件定義に進む場合は `/requirements` を実行してください。
domain-analyst が生成したヒアリング質問をクライアントミーティングの前に確認してください。
